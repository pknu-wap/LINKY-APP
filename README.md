## 📖 개요 (Overview)

**LINKY**는 단순히 링크를 저장하는 것을 넘어, 사용자가 수집한 정보의 가치를 극대화하는 **AI 기반 링크 아카이빙 서비스**입니다.
저장만 하고 잊어버리는 파편화된 정보들을 AI가 분석하고 요약하여, 언제든 필요할 때 다시 꺼내 볼 수 있는 지식 창고로 만들어줍니다.

---

## ✨ 핵심 기능 (Key Features)

### 🚀 스마트 아카이빙

- **간편한 저장**: 앱 외부 공유 기능을 통해 브라우저나 타 앱에서 즉시 링크를 LINKY로 전달할 수 있습니다.
- **카테고리 분류**: 저장된 링크를 사용자가 정의한 카테고리별로 체계적으로 관리합니다.

### 🧠 AI 분석 (Gemini AI)

- **자동 요약**: 긴 글이나 복잡한 웹 페이지의 내용을 AI가 핵심만 요약하여 제공합니다.
- **자동 분류**: 링크의 내용을 분석하여 적절한 카테고리를 추천하거나 자동 분류합니다.

### 🔔 지능형 리마인더

- **맞춤형 알림**: 나중에 읽기로 한 링크를 잊지 않도록, 사용자가 원하는 시간에 맞춰 푸시 알림을 제공합니다.
- **사전 알림 기능**: 설정된 시간 30분 전에 미리 알려주는 세심한 리마인더 시스템을 갖추고 있습니다.

### 🔒 보안 및 편의성

- **나만보기 (Private)**: 민감한 링크는 암호 설정을 통해 본인만 확인할 수 있도록 안전하게 보관합니다.

## 🛠 기술 스택 (Tech Stack)

### Frontend

- **Framework**: Flutter
- **State Management**: Provider
- **Local Storage**: Flutter Secure Storage, SharedPreferences
- **Communication**: HTTP, Flutter Sharing Intent
- **Notification**: Flutter Local Notifications, Android Alarm Manager Plus

### Backend

- **Framework**: Spring Boot
- **Database**: MySQL, Redis (Optional)
- **Authentication**: OAuth 2.0 (Kakao)
- **AI Integration**: Google Gemini API
